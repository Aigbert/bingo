   看一下 session/queue.rs 里的 steer 逻辑，为什么排队的消息有时候会被吞掉                      4s  
   先看 queue.rs，再看谁在调用 drain() 和 reset()。

   问题不在 drain()，在 reset()：每一轮开始时，它把 queue 整个清空了。                              
                                                                                                    
                                                                                            rust    
     pub fn reset(&mut self) {                                                                      
         self.queue.clear();   // 排着的消息在这里丢了                                              
         self.steer = None;                                                                         
     }                                                                                              
                                                                                                    
                                                                                                    
   你先插了一句（steer），又排了一句（queue）：steer 让这一轮提前收尾，下一轮开始时 reset() 把还没  
 ⠠ 发出去的那句一起清掉了。所以只有「插话之后紧跟着排队」才会丢。
