整个界面只有一种强调色：ember 橙。bingo 在忙，它是沿着输入区上沿跑过的一道彗星；需要你，它变成琥珀色，输入区就地变成那个问题；做完了，这一轮左边那道光由橙转绿，溅出三颗火星。其余的一切都保持安静：每一步落成一行，带着自己的图标；页脚只写例外。

03 · 设计系统

东西很少，每一样都有用处

一种强调色、一套网格、一张记号表、一组节奏、八种动效、一张按键表。实现时它们就是常量，屏幕上的每一格都能追溯到这里。

不繁琐

三条带，一个动作区

对话在上，输入区在下，页脚一行。询问、面板、搜索都在输入区里就地展开，从不叠窗口，也从不抢走你正在打的字。

有设计感

一种强调色，一套网格

底色和文字色取自你的终端，只加一种 ember 橙表示注意力。所有内容对齐到第 0、3、5、13 列四条竖线。

屏蔽冗余

一步一行，图标说是什么

每一步落成一行，图标、动词、参数、结果各在自己的列上；查东西的暗一档，动手的亮一档。输出收在行里，点开才看；只有最后一步失败的输出会留在屏幕上等你看。

灵动

只在状态变化时动

彗星表示在忙，呼吸表示在等你，火星表示做完了。状态不变就不动；打开减少动效，一切都变成静止的。

人机交互

一个键只有一个意思

esc 永远是停下或退一步，⏎ 永远是确定。它在跑的时候，⏎ 插话、tab 排队，你打字从来不会打断它。

解剖

正在进行的一轮。上一轮的每一步都留在原地；这一轮左边的光在呼吸，正在跑的一步在转圈，彗星沿着输入区上沿跑，你排队的话等在输入框上面。

    网格

    四条竖线管住所有内容：边光在第 0 列，文字和图标从第 3 列开始，动词和井从第 5 列开始，步骤的参数对齐在第 13 列。右边留 2 列，正文最宽 100 列，宽屏上也不会拉成一长条。

    ctrl+o 细节。虚线是网格，上面的数字是列号。

    记号

    十几个记号，每个只有一种意思，每个都有 ASCII 替身。终端不支持的时候，换成替身照样能读。

    工具图标

    每一步前面的图标由这个工具所属的 mod 声明，和动词、参数的读法写在一起。内置功能本身就是 mod，外面装的 mod 和 MCP 服务器用同一份声明；没声明的工具是一个圆点加工具名。图标都取自等宽字体自带的字符，粗细和正文一致，SF Mono、Menlo、JetBrains Mono、Cascadia 都自带；每个都有 ASCII 替身，不是一格宽的字符一律退回圆点。

    一轮里用到的所有图标。查东西的暗一档，动手的亮一档；队友用它自己的颜色。

    哪一块谁说了算怎么画
    图标、动词、参数的读法工具的声明（ToolSpec）mod 注册工具时一起声明；TUI 不认识任何一个工具名
    右边的结果工具返回的一句话214 lines、12 passed、+1 −1，由工具自己写
    打开后的井mod 的 ToolOutput.displaydiff、带行号的代码、命令输出、问答……mod 想怎么画就怎么画
    整行Ledger 站点mod 可以接管自己工具的那一行，比如队友那一行用它的颜色

    颜色

    底色和文字色取自你的终端：浅色 #f9f4f2 / #3a342e，深色 #2c2a2e / #e6e2dc。灰阶都是这两种颜色的混合；强调色只有 ember 一种，绿、红、琥珀只表示结果和等待。

    节奏

    空行是唯一的分隔符。没有边框，没有分割线，整个屏幕只有输入区上沿那一条横线。

    之间空行为什么
    两轮对话之间1一轮是一个整体，一行空白就够分开
    你的话 → 第一步0步骤是这句话引出来的，紧贴着它
    步骤之间0一步一行，旁白夹在中间，读起来是连着的一串
    最后一步 → 回答1回答是要认真读的正文，给它留出呼吸
    回答里的块之间1段落、代码、列表各成一块；标题后面不空行，它属于下面那块
    对话 → 输入区上沿1上沿是屏幕上唯一的横线，不贴着字
    输入区 → 页脚1页脚是背景信息，往后退一步
    面板标题 → 列表1标题说这是什么，列表是让你选的

    动效

    动效只表达状态的变化，每一种都有固定的时长。打开减少动效后，彗星变成一条静止的淡线，呼吸停在一帧，火星不再出现。

    动效样子时长什么时候出现
    彗星
    		2200 ms 一趟bingo 在忙。头亮尾冷，沿着输入区上沿跑
    边光
    		320 ms 转绿，700 ms 火星一轮做完。边光由橙转绿，溅出三颗火星
    呼吸
    		1400 ms需要你。上沿变成琥珀色并呼吸；危险操作是红色，不呼吸
    转圈
    		80 ms 一帧，落地 420 ms正在跑的那一步；跑完落成这一步的图标，从 ember 色褪到本色
    流光
    		2400 ms在想，还没有动手
    光标
    		1200 ms等你输入。柔和地明暗，从不硬闪
    余温
    		最后 10 个字回答正在写出来，最新的字还带着 ember 的余温
    提示
    		160 / 2400 / 300 ms确认一个动作。借用页脚左侧，然后还给原来的信息

    另外两种不在表里：输入区变高时每 14 ms 长出一行，变矮时立刻收回；欢迎页的字在你开口时化成光点飘走，用时 520 ms。

    按键

    同一个键在哪里都是同一个意思。页脚右侧只列出此刻能用的键。

    esc停下，或者退一步在你的会话里：在跑就停下，在问你就是拒绝并停下；没在跑时，依次清空草稿、回到底部。在队友或房间里，esc 从不停下什么，只带你回来。
    ⏎ / tab插话，或者排队它在跑的时候，⏎ 让这句话在下一步落地，tab 等这一轮结束再发。
    ↑拿回排队的话输入框空着时，↑ 先取回最后排队的那一句，再往前翻历史。
    ctrl+c一层一层收起停下、关面板、收起细节、清空输入。什么都没有时，再按一次才退出。
    ctrl+g去等你的那个队友的询问在它自己的会话里等你；页脚写着谁在等，ctrl+g 直接过去，esc 回来。
    esc esc回到某一句之前输入框空着时连按两次，打开回退列表；对话和文件一起回去。
    ctrl+o看这一轮的细节步骤一直都在；ctrl+o 再加上想了什么和你插的话，↑↓ 选一步，⏎ 打开它的输出或 diff，esc 收起。
    ctrl+b把命令放到后台耗时的命令转到后台，这一轮照常结束；跑完会在对话里报一声。
    /命令和技能技能也在这里，右边写着它的来源。打字即过滤，tab 补全。
    @引用文件或协作者模糊匹配仓库里的文件和协作者，tab 插入；在房间里 @ 谁，谁就欠你一句回答。
    !直接跑 shell以 ! 开头的一行直接交给 shell，输出留在对话里。
    ⇧tab切换模式默认、自动接受修改、只做计划、全部放行，依次切换；上沿闪一下颜色确认。
    ?所有按键输入框空着时按 ?，按键按场合分组列出。

    需要你拍板的七件事

    这七条决定了实现的形状。你点头之后，我按上面的顺序开工。

    1. 只有一种强调色

      界面只用 ember 橙表示注意力；绿、红、琥珀只表示结果和等待。代码高亮和协作者的颜色不算强调色。

    2. 询问进输入区，esc 就是停下

      询问不再弹框，输入区就地变成选项列表。esc 拒绝并停下这一轮；想说明原因，直接打字。在队友的会话里，esc 只带你回来。

    3. 一步一行，每个工具有自己的图标

      一行一行往下推，做完也不折叠。图标取自等宽字体自带的字符，由工具所属的 mod 声明，转圈跑完落成图标；颜色只说状态：失败红、等你琥珀、查东西暗一档。点一下打开输出，ctrl+o 看想了什么。

    4. ⏎ 插话，tab 排队

      它在跑时，⏎ 让这句话在下一步落地，tab 等这一轮结束；↑ 拿回排队的话，按 esc 停下时排队的话回到输入框。

    5. 页脚只写例外

      平时只显示模型和思考强度；模式、上下文、后台命令、协作者、定时唤醒只在不寻常时出现。

    6. 退出时留一行收据和 --resume

      退出后终端里留下一行收据：几轮、多久、改了几个文件，下一行就是 bingo --resume 加这个会话的 id，回来的一定是这一个会话。

    7. 你的输入区只属于你

      队友要你点头时，询问留在它自己的会话里，不抢你的输入区；页脚写着谁在等你，ctrl+g 过去，esc 回来。房间里 @ 谁，谁就欠你一句回答。
