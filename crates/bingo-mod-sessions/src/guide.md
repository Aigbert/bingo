# Sessions

`/sessions` opens the session sheet in the dock. Type to filter by title or directory.
Sessions that need you come first, followed by working sessions and then filter score.
Up/Down selects a row; Enter resumes it; Escape closes the sheet and restores the draft.

An unnamed session takes its first ask as its title. `/rename` always wins.
Disable `bingo.mod.sessions` to turn off the directory and auto-titling.
